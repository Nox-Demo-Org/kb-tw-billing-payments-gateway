# Components and data models

One page per significant component and core data model.

## Pages

- [Collection Request](/entities/collection-request.md) — The collect.Request struct represents the payload accepted by the POST /v1/collections endpoint in payments-gateway.
- [Payout Request](/entities/payout-request.md) — The payout.Request entity defines the data model and execution contract for claim disbursements.
- [PSP Client](/entities/psp-client.md) — The PSP Client provides the HTTP communication layer between payments-gateway and the external Payment Service Provider (PSP).
